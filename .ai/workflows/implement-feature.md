# Implement Feature Workflow

1. Read `AI_CONTEXT.md`.
2. Identify SRS/DDD requirement and related Test Case rows.
3. Read public API, proto and event contracts for the feature.
4. Implement inside the owning service; never read another service DB.
5. Add/update tests.
6. Run syntax/config/unit/integration checks.
7. Verify related 30-rubric smoke if applicable.
8. Commit only after passing.
